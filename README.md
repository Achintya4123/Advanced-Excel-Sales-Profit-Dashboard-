# Interactive Sales & Profit Performance Dashboard

 Project Overview

An end-to-end Business Intelligence project developed using
Advanced Microsoft Excel to analyze sales, profit, regional
performance, category performance and target achievement.

Business Problem

Management needs an interactive way to monitor sales and profit
performance across years, regions and product categories.

Objectives

- Analyze yearly sales and profit trends
- Compare regional performance
- Identify high-performing categories
- Track sales and profit targets
- Calculate target achievement
- Build an interactive management dashboard

Tools & Technologies

- Microsoft Excel
- Power Query
- PivotTables
- PivotCharts
- XLOOKUP
- INDEX-MATCH
- SUMIFS
- Dynamic Arrays
- Slicers
- Conditional Formatting

Data Preparation

Power Query was used for:

- Data type standardization
- Data quality validation
- Shipping calculations
- Profit margin calculation
- Data transformation

 Analysis

The project includes:

- Regional performance analysis
- Yearly sales/profit trend analysis
- Category performance analysis
- Sales target analysis
- Profit target analysis
- Target achievement analysis

Dashboard Features

- KPI cards
- Year slicer
- Region slicer
- Category slicer
- Yearly trend chart
- Regional performance chart
- Category performance chart
- Target achievement indicators

Key KPIs

- Total Sales
- Total Profit
- Average Order Sales
- Average Profit Margin
- Sales Target Hit Rate
